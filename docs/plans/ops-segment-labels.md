## 실행 전 영향 측정 (읽기 전용)

부트스트랩(`value.bootstrap_eta`, `efficiency.bootstrap_rank_corr`)은 난수 하나를 그룹 이름 순서대로 나눠 쓴다. 새 이름에서는 "없음"이 "있음"보다 앞에 정렬되므로 난수 배정이 바뀐다. 이름만 바꿔 메모리에서 다시 계산한 결과:

| 항목 | 변화 | 판정 |
|---|---|---|
| 점추정(η, 성사율, ρ) | 동일 | — |
| 금액 축 구간 | 동일 | 유지 |
| 접수 경로 축 구간 | 최대 0.7% | 유지 (구간 분리) |
| 세그먼트 η 구간 | 중앙값 0.6%, 최대 3.2% | — |
| ρ(성사율, η) 90% 구간 | 0.609~0.691 → 0.616~0.692 | "다르다" 유지 (상한 < 0.7) |
| 참고: 옛 이름에서 시드 0~9 | 상한 0.687~0.699 | 10/10 시드에서 < 0.7 |

→ 이동은 몬테카를로 오차 범위 안이다. 판정은 바뀌지 않는다.
