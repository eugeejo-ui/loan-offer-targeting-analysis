## 계산기(MVP)

**목적:** Phase 9의 FR1·FR2·MR1이 정의한 규칙이 실제로 계산되는지 확인하는 최소 도구다. 예측 모델이 아니라 **규칙표 계산기**다. 알 수 없는 두 값(시간당 비용, 순마진 비중)을 사용자가 바꿔 가며 세그먼트의 부호와 순위가 어떻게 움직이는지 본다.

**입력:** `outputs/p5_calculator_input.csv`, `outputs/p5_calculator_meta.json` (Phase 5 산출)

**구조:**

| 파일 | 책임 |
|---|---|
| `analysis/calculator.py` | 계산 로직. Streamlit을 import하지 않는다 — 테스트 가능하게 분리 |
| `app/calculator_app.py` | 화면. 입력 위젯과 표·요약만 담당 |
| `tests/test_calculator.py` | 부호 판정·필요 순마진 비중·배분 비교의 경계 사례 |

**화면 구성:**
1. 입력 — 시간당 비용(유로), 총이자 중 순마진 비중(%)
2. 세그먼트 표 — η 순 정렬, 신청당 기대값과 부호, 필요 최소 순마진 비중
3. 요약 — 음수 세그먼트 수와 그 신청·공수 비중, 부호가 뒤집히는 임계 비중
4. 배분 비교 — 공수 예산을 정하면 효율 순서와 성사율 순서의 기대 대출 규모 차이

**판정 규칙 (착수 전 고정):**
1. 계산은 Phase 3·5의 정의를 그대로 쓴다. 새 지표를 만들지 않는다.
2. 기본값은 참조 인건비 57.6유로/시간이고, 그 근거(Eurostat, 네덜란드 금융·보험업 2016)를 화면에 적는다.
3. 세그먼트 순위는 두 입력과 무관하다는 점을 화면에서 보여준다 (P1).
4. 예측·추천 문구를 쓰지 않는다. 계산기는 "이 가정에서 부호가 어떻게 되는가"만 답한다.
5. 데이터가 없으면(캐시 미생성) 안내 문구를 띄우고 종료한다. 예외로 죽지 않는다.
