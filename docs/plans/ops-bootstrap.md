# 부트스트랩 반복 수 보강 — 계획과 기록

> Phase 공통 운영 작업 (2026-09-11). 사용자 결정: "권고안대로 진행". 선행 작업: [`ops-segment-labels.md`](ops-segment-labels.md)

## 왜

- 핵심 결론("성사율 순위와 효율 순위는 다르다")은 ρ(성사율, η)의 90% 부트스트랩 구간 상한이 0.7 아래라는 데 기댄다 (Phase 5 판정 규칙 ①).
- 반복 200회에서는 시드만 바꿔도 상한이 0.687~0.699로 움직였다(옛 이름, 시드 0~9 — 임시 점검 스크립트). 판정이 난수 오차 범위에 걸쳐 있었다.
- 세그먼트 이름만 바꿔도 구간이 움직였다(0.609~0.691 → 0.616~0.692). 난수가 그룹 이름 순서로 배정되기 때문이다.
- Phase 10·README·발표가 이 구간을 인용하므로, 보강은 지금이 가장 싸다.

| 하지 않는 것 | 그룹별 독립 시드(이름 순서 무관화). 반복 2,000에서는 이름 순서의 영향도 난수 오차 수준으로 줄어든다. 케이스 ID 기반 시드는 복잡도에 비해 얻는 것이 작다 |

## 판정 처리 (착수 전 고정)

- 상한 < 0.7 → 판정 유지("다르다").
- 상한 ≥ 0.7 → Phase 5 규칙 ①대로 "구간이 경계를 걸친다"로 두 판정을 함께 적는다. 기준은 조정하지 않는다. 배분 이득 +13.2%와 어긋남 목록은 난수와 무관하므로 핵심 서술은 유지된다.
- 축 유지 판정(Phase 4, 구간 분리)이 바뀌면 멈추고 보고한다.
