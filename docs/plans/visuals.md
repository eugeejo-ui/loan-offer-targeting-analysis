# 시각화 — 선별 제작 계획과 기록

> Phase 공통 작업. Phase 0~9 진행계획에는 "차트는 만들지 않는다(산출물 단계에서 일괄 제작)"는 제약이 있었다. 2026-09-11 사용자 요청으로, 산출물 단계 전에 **도표가 설명을 확실히 줄여주는 곳만** 골라 만든다.

## 원칙

- **Phase마다 하나씩 만들지 않는다.** 표나 한 줄 수치로 충분한 곳(Phase 0·2·3·4)은 만들지 않는다.
- dataviz 스킬 절차를 따른다. 형태 먼저, 색은 나중, 팔레트는 검증 스크립트로 확인하고, 렌더링한 결과를 눈으로 확인한다.
- 색: 참조 팔레트의 첫 3색(파랑 `#2a78d6`, 주황 `#eb6834`, 청록 `#1baf7a`)만 쓴다. 산점도처럼 모든 쌍이 구분돼야 하는 형태에서는 3색까지만 검증되기 때문이다. 강조 형태는 1색 + 회색(`#c3c2b7`)을 쓴다.
- 이중 축 금지. 성격이 다른 두 지표는 나란히 둔 두 패널로 그린다.
- 라벨은 선택적으로만 붙인다. 모든 점에 숫자를 달지 않는다.
- 텍스트는 잉크 색(`#0b0b0b`, `#52514e`, `#898781`)만 쓴다.
- 모든 차트 아래에 출처 파일을 적는다. 수치는 `outputs/`에서 읽는다.
- 한글 폰트는 Malgun Gothic, 표면색은 `#fcfcfb`다. PNG 정적 이미지이므로 다크 모드와 호버는 적용하지 않는다(문서 삽입용).
